# Contributing to VaraStudy Vault

Thank you for your interest in contributing to VaraStudy Vault.

## How to Contribute

You can help improve the project by:

- Reporting bugs and unexpected behavior.
- Suggesting new features or improvements.
- Improving documentation.
- Submitting code changes through pull requests.

## Before Submitting Changes

- Describe the problem or improvement clearly.
- Keep changes focused and easy to review.
- Test theme functionality on a development or staging WordPress site.
- Check compatibility with the required custom post types and Advanced Custom Fields (ACF).
- Update documentation when necessary.

## Bug Reports and Feature Requests

Open an issue in the GitHub repository. Include the relevant steps to reproduce a bug, expected behavior, actual behavior, and your WordPress/PHP versions when applicable.

## Code Contributions

1. Fork the repository.
2. Create a branch for your changes.
3. Make and test your changes.
4. Submit a pull request describing what changed and why.

By submitting a contribution, you agree that your contribution will be distributed under the project's GPL-2.0-or-later license.

Thank you for helping improve VaraStudy Vault!
